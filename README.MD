# K9 Project

Bu depo, Flutter ile geliştirilmiş **K9 Vital Monitor** mobil uygulamasını içerir.

## Proje Yapısı

- `k9_app/`: Uygulamanın tüm kaynak kodları

## Özellikler

- Giriş / kayıt ekranları
- Alt sekmeli gezinme yapısı
- Canlı izleme ekranı ve kamera kartları
- Gerçek zamanlı sağlık grafik bileşenleri (ör. kalp atışı, SpO2)
- Sohbet ekranları
- Tema (açık/koyu) desteği

## Gereksinimler

- Flutter SDK (Dart 3.8+)

## Kurulum

```bash
cd k9_app
flutter pub get
```

## Çalıştırma

```bash
cd k9_app
flutter run
```

## Test ve Analiz

```bash
cd k9_app
flutter analyze
flutter test
```
